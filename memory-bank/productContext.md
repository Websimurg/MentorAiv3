# Product Context

## Why This Project Exists
MentorAi³ addresses the growing need for accessible, personalized mental wellness and personal development tools. Many people struggle with:
- Lack of consistent mentorship and guidance
- Difficulty tracking personal growth
- Inconsistent meditation and mindfulness practices
- Poor nutrition awareness and tracking
- Need for daily motivation and affirmations

## Problems It Solves

### 1. Accessibility
- **Problem**: Traditional mentorship is expensive and time-consuming
- **Solution**: AI-powered 24/7 mentorship available instantly

### 2. Nutrition Tracking
- **Problem**: Manual calorie counting is tedious and inaccurate
- **Solution**: AI vision analysis of food photos for instant nutritional data

### 3. Habit Formation
- **Problem**: Hard to maintain meditation and wellness routines
- **Solution**: Integrated tracking, reminders, and progress visualization

### 4. Motivation
- **Problem**: Lack of daily encouragement and positive reinforcement
- **Solution**: Personalized mantras and motivational content

## How It Should Work

### User Journey
1. **Entry**: User lands on beautiful gradient homepage
2. **Onboarding**: Quick introduction to features
3. **Dashboard**: Central hub showing progress and quick actions
4. **Feature Usage**: 
   - Chat with AI for guidance
   - Upload food photos for instant analysis
   - Start meditation sessions with timer
   - Read and repeat daily mantras
5. **Progress**: View stats, achievements, and growth over time

### User Experience Goals
- **Delightful**: Beautiful gradients, smooth animations, emoji icons
- **Intuitive**: Clear navigation, obvious actions, minimal learning curve
- **Fast**: Instant responses, no loading delays, smooth transitions
- **Motivating**: Positive feedback, progress visualization, encouraging messages
- **Personal**: Feels like a personal mentor, not a cold tool

## Key User Flows

### Calorie Tracking Flow
1. Navigate to Kalori page
2. Click camera icon or upload button
3. Select/capture food photo
4. AI analyzes image (shows loading state)
5. Results display: food name, calories, macros
6. Meal added to daily log
7. Dashboard updates with new data

### Meditation Flow
1. Navigate to Meditasyon page
2. Choose duration (5, 10, 15, 20 min)
3. Click "Başlat" (Start)
4. Timer counts up with calming UI
5. Pause or finish session
6. Session logged to history
7. Dashboard shows total meditation time

### AI Chat Flow
1. Navigate to AI Chat page
2. See welcoming message from AI
3. Type question or concern
4. Receive thoughtful, personalized response
5. Continue conversation naturally
6. Chat history persists in session

## Design Philosophy
- **Gradient-Heavy**: Pink → Purple → Blue gradients throughout
- **Emoji-Rich**: Use emojis for visual interest and quick recognition
- **Card-Based**: White cards with shadows on gradient backgrounds
- **Rounded**: Generous border-radius on all elements
- **Spacious**: Plenty of padding and whitespace
- **Responsive**: Mobile-first, works beautifully on all screens
