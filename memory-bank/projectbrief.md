# Project Brief: MentorAi³

## Project Overview
MentorAi³ is a personal transformation mentorship platform powered by AI. It helps users achieve mental clarity, self-discipline, and mindfulness through various interactive features.

## Core Purpose
- Provide AI-powered personal mentorship
- Track and improve mental wellness
- Support habit formation and goal achievement
- Offer guided meditation and mindfulness practices
- Enable nutrition tracking through AI image analysis

## Key Features
1. **AI Chat** - Personalized mentorship conversations with AI
2. **Kalori (Calorie Tracking)** - Food photo analysis using OpenAI Vision API
3. **Meditasyon (Meditation)** - Guided meditation sessions with timer
4. **Mantra** - Daily affirmations and motivational content
5. **Dashboard** - Progress tracking and activity overview
6. **Admin Panel** - System management and configuration

## Target Users
- Individuals seeking personal development
- Users interested in mindfulness and meditation
- People wanting to track nutrition and wellness
- Turkish-speaking audience (UI in Turkish)

## Success Criteria
- Intuitive, beautiful UI with modern design
- Seamless AI integration for chat and image analysis
- Real-time progress tracking
- Responsive design for all devices
- Fast performance and smooth user experience

## Technical Constraints
- Must use Next.js 16.0.0 with App Router
- TypeScript for type safety
- Tailwind CSS for styling
- OpenAI API for AI features
- Client-side state management with React hooks
- LocalStorage for data persistence
